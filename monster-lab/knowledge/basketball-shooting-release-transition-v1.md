# 籃球投籃動作分析優先級

2. **第二優先：移動 → 提前降重心 → 起跳。**

這是 IMG_4216 案例及類似問題的分析順序，不代表所有投籃者都必然有相同缺點。工具應先確認影片證據，再套用修正建議。

## 第一優先：Release direction／側甩

### 問題定義

出手最後階段，投籃手的手腕、手掌或手指出現向側邊偏轉的傾向，導致最後出手方向的一致性值得檢查。即使球的上升路徑、出手高度與手肘伸展看起來良好，也不能據此判定離手方向正確。

IMG_4216 的既有結論：手肘向上、向前延伸與前臂路徑大致正常，但最後 wrist snap 時，右手掌／手指有側向偏轉。分析焦點應放在最後出手方向，而非直接認定整條手臂或手肘嚴重歪斜。

**Follow-through 完整不等於方向正確。**完整伸肘與壓腕描述的是動作完成度；最後手腕、手指與前臂朝向描述的是方向，兩者須分開判斷。

### 影片判斷特徵

必須依序檢查：

> **球在手上的位置 → elbow extension → wrist snap → 最後離球手指 → follow-through 指向。**

| 檢查階段 | 觀察內容 | 判斷限制 |
|---|---|---|
| 球在手上的位置 | 球上升至出手準備位置時，投籃手是否明顯偏球側面；是否在後續動作中出現補償性轉動 | 單一視角未必能確認掌心與球的相對位置 |
| Elbow extension／伸肘 | 手肘與前臂是否沿穩定路徑向上、向前伸展；區分整臂側移與末端偏轉 | 不以手肘必須絕對垂直作為唯一標準 |
| Wrist snap／壓腕 | 球離手前後，手掌／手指是否明顯向側邊甩；偏轉發生於離手前、離手中或離手後 | 離手後的手部偏轉，不能單獨證明球受到側向力量 |
| 最後離球手指 | 可辨識時，記錄最後接觸球的手指與接觸方向 | 若遮擋、模糊或幀率不足，標示「無法判定」，不得猜測 |
| Follow-through 指向 | 出手後短暫停留時，手指、手腕與前臂是否大致延續朝籃框的方向 | 必須結合離手瞬間，不能只看最後定格 |

優先比較同一投籃者多次出手；有條件時使用正面／後方與側面互補視角，並觀察偏轉是否反覆出現。球的旋轉與左右落點可作為輔助資訊，但不能單靠一次左右偏投反推原因。

### 正確／錯誤動作模式

- **目標模式：**球在手上的位置穩定 → 手肘與前臂自然伸展 → 手腕、手指延續朝籃框的出手意圖 → 球離手 → follow-through 保持自然且方向一致。
- **需檢查模式：**手肘路徑大致正常 → 離手前後手掌／手指明顯側轉 → 多次出手出現相似方向偏差。
- **不可直接判錯：**球已離手後才出現自然手部旋轉，且未見離手前的方向異常。

「Elbow → Wrist → Fingers → Rim」是方向提示，不是要求所有關節在畫面上形成絕對直線，也不應強迫每個人使用同一根手指最後離球。

### 修正 cue

> **FINGERS THROUGH THE RIM／手指穿過籃框。**

以朝向籃框的出手意圖引導動作，避免僵硬地控制手腕。可在近距離、舒適力度下投籃，出手後自然停留約一秒，檢查手指、手腕與前臂是否大致延續朝籃框的方向，再以多次出手影片確認一致性。

「停留一秒」用於觀察，不應為了定格而刻意扭手腕或改造已完成的 follow-through。

### 原因推測規則

既有分析曾提出「投籃手稍偏球側面，最後以側向轉動完成出手」的可能解釋。工具只能將其列為**待確認假設**；二維影片通常不足以直接確認力量是否穿過球心、側向力量大小或確切因果。

## 第二優先：移動 → 提前降重心 → 起跳

### 問題定義

移動至投籃位置後，才額外降重心與準備起跳，可能增加一拍準備時間，使急停與投籃銜接不夠連續。改善方向是在接近投籃位置時，配合步伐提前開始降低重心，到點／煞停後銜接人球一起上升。

### 影片判斷特徵

- 觀察最後幾步、接球／收球、屈髖屈膝、煞停與起跳的時間關係。
- 檢查是否「腳已到位 → 停頓 → 才明顯下沉 → 起跳」，而非只用某一格膝蓋彎曲程度判斷。
- 檢查接近到點時是否已逐步降重心，並在控制好身體與步伐後銜接向上發力。
- 分開觀察身體降重心與球的 dip；兩者需配合，但不是同一件事，也不要求所有情境完全同時。
- 比較接球投、一步急停、左右移動後投籃；確認節奏、平衡與落地控制是否可重複。

### 正確／錯誤動作模式

**需改善模式：**

> 移動 → 到點 → 額外降重心 ↓ → 起跳 ↑。

**目標模式：**

> 移動 → 提前降重心 ↓ → 到點／煞停 → 人球一起 ↑。

目標是減少不必要的準備停頓，不是取消必要煞停、強迫全速起跳，或在尚未控制平衡時急著出手。

### 修正 cue

> **LOW BEFORE YOU ARRIVE → RISE WITH THE BALL**
>
> **到點之前先降重心，到點之後人球一起上。**

靜態投籃可保留簡短提示：**RISE WITH THE BALL／人球一起上。**移動投籃則加入提前降重心的提示，先在可控制的速度下確認銜接，再逐步提高實戰速度。

## 分析優先順序與回饋規則

1. **確認證據品質：**交代拍攝角度、遮擋、清晰度與可判定範圍；無法看清離手瞬間時，不給確定的側甩結論。
2. **先檢查 Release direction：**依完整檢查鏈逐項觀察，區分離手前後偏轉，並將完成度與方向分開。
3. **若側甩有明確證據，列為第一修正重點：**先使用「手指穿過籃框」，避免同時加入多個手腕與手掌控制指令。
4. **再檢查移動銜接：**評估提前降重心、煞停與人球上升的時間關係，列為第二修正重點。
5. **若未見側甩證據：**明確記錄「本片未觀察到」或「無法判定」，再依實際問題安排訓練重點；不得為符合案例而硬套缺點。
6. **用多次出手驗證：**單球只能描述該次表現；穩定性、習慣性問題與改善成效需跨多次出手比較。

建議回饋順序為「可見特徵 → 判斷與信心 → 優先級 → 一個主要 cue → 驗證方式」。原因推測須與可見事實分開呈現。

## 避免錯誤建議

- 不因整體流暢、出手高或 follow-through 完整，就略過最後出手方向。
- 不把末端手腕／手指側轉直接描述成「手肘整個往旁邊甩」。
- 不要求「硬把手腕轉正」「手腕絕對不能歪」，避免增加不必要的前臂緊繃。
- 不在證據不足時要求掌心刻意塞到球正下方，或增加 wrist load／手腕後伸。
- 不要求球一定拉到頭頂；IMG_4216 既有分析中的「胸前 → 臉前 → 經過額頭 → 頭部上方前側離手」路徑，沒有僅因高度而大改的理由。
- 不強迫完全垂直、零向前位移；應結合平衡、出手一致性與落地控制判斷。
- 不將單一左右 miss 或離手後手腕偏轉，當作側向施力的確證。
- 不在最後離手方向尚未確認時，把所有注意力只放在移動銜接。

## 評分注意事項

評分須分項、附觀察依據與信心程度。影像不足時使用「無法判定」，不得以高分掩蓋未檢查項目。單球分數不代表長期能力，也不是量測得到的生物力學精度。

| 出手高度 | 9 | 高度與方向是不同項目 |
| 手肘路徑 | 8～8.5 | 不把末端偏轉混同整臂路徑問題 |
| Follow-through 完整度 | 9 → 8.5 | 評估伸展與壓腕是否完成 |
| Follow-through 方向 | 7.5～8 | 必須獨立評估並結合離手瞬間 |

## 工具輸出必備欄位

- **影片／案例識別：**檔名或片段名稱。
- **證據品質：**可見角度、離手瞬間是否清楚、判斷限制。
- **第一優先判斷：**Release direction／側甩的可見特徵、發生時機與信心程度。
- **完整檢查鏈：**球在手上的位置 → elbow extension → wrist snap → 最後離球手指 → follow-through 指向；逐項記錄或標示無法判定。
- **第二優先判斷：**移動、提前降重心、煞停與起跳的銜接。
- **主要 cue：**第一優先「FINGERS THROUGH THE RIM／手指穿過籃框」；第二優先「LOW BEFORE YOU ARRIVE → RISE WITH THE BALL／到點之前先降重心，到點之後人球一起上」。
- **評分與驗證：**完成度、方向與穩定性分開說明；以後續多次出手確認改善。
